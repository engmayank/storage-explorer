# Storage Explorer

Interactive guide to Kubernetes storage for the CKA exam: PVC → PV chain, provisioning lifecycle, volume picker, terms, copy-ready YAML, debugging table and exam drills.

**Live:** https://engmayank.github.io/storage-explorer/

Companion to [CKA Explorer](https://engmayank.github.io/cka-explorer/).

## Run locally
Open `index.html` in any browser. No build step.
